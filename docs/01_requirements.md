# 요구사항 정의서 — Can I run this model?

## 1. 도메인 확정

**도메인: 로컬 LLM 실행 가능성 안내 (오픈 모델 × 개인 PC 하드웨어)**

로컬에서 오픈 LLM을 돌리려는 사용자가 "이 모델이 내 PC에서 돌아가는가, 얼마나 빠른가, 어떤 양자화를 써야 하는가,
상업적으로 써도 되는가"를 묻는다. 답은 모델마다 다른 사양(파라미터 수, 레이어 수, KV 헤드, 컨텍스트 길이)과 모델 카드·라이선스
원문에 있고, 하드웨어에 따라 결론이 달라지므로 근거 없이 답하면 틀리기 쉽다.

### 1.1 도메인 선택 조건 충족 근거

| 조건 | 충족 근거 |
|---|---|
| **항목 메타데이터 약 100건 이상** | Hugging Face Hub API에서 다운로드순 text-generation 모델 **150건** 수집 (`data/models.json`, 2026-10-21 스냅샷). 항목마다 모델 ID, 제작사, 파라미터 수(safetensors 기준), 아키텍처, 레이어 수, hidden size, 어텐션 헤드, KV 헤드, 헤드 차원, 최대 컨텍스트, MoE 전문가 수, 라이선스(+원문 링크), 지원 언어, 기반 모델, 태그, 다운로드 수, 수정일, HF URL |
| **항목마다 연결되는 설명 문서** | 모든 항목에 **HF 모델 카드**(저장소 README)가 1:1로 있다. 추가로 **라이선스 원문**(LICENSE), 모델 카드가 연결한 **arXiv 기술 보고서 PDF**, 개념 설명용 **한국어 위키백과** |
| **출처와 이용 조건 기록** | `data/SOURCES.md` — HF 서비스 약관과 모델별 라이선스, 위키백과 CC BY-SA 4.0, arXiv 논문별 라이선스·호출 간격, 하드웨어 사양 출처 URL, 양자화 bpw 출처 |
| **근거가 필요한 질문** | 아래 1.2. 실제로 근거 없이(RAG 없이) 같은 LLM에 물었을 때 틀린 답을 단정적으로 냈다 (`docs/eval/rag_comparison.md`) |
| **위험 도메인 여부** | 건강·금융처럼 판단이 위험한 도메인은 아니다. 다만 ① **라이선스·상업적 이용 질문은 법률 판단에 가까워** 답변 끝에 "법률 자문이 아니며, 정확한 조건은 원문 라이선스를 확인하세요."를 코드에서 반드시 붙이고, ② 실행 가능 판정·속도는 **추정치(계산값)** 임을 화면과 답변에 표시한다 |

### 1.2 근거 없이 답하면 틀리는 질문 (실측)

같은 LLM(`gpt-4o-mini`)에 근거 없이 물은 답과 정답(근거)이다. 전체는 `docs/eval/rag_comparison.md`.

| 질문 | 근거 없이 답한 내용 | 정답 (근거) |
|---|---|---|
| Qwen3-8B의 레이어 수와 KV 헤드 수는? | 레이어 32, KV 헤드 16 | 레이어 36, KV 헤드 8 (config.json) |
| thinking 모드 권장 샘플링 설정은? | Temperature 0.7, TopP 0.9, TopK 50 | 0.6 / 0.95 / 20 (모델 카드) |
| Qwen3는 사전 학습에 토큰을 얼마나 썼나? | 약 1.5조 | 36조 (기술 보고서 p.3) |
| Nemotron-3-Nano-30B-A3B의 최대 컨텍스트는? | 2048 | 262,144 (config.json) |
| RTX 3080(10GB)에서 Qwen3-8B Q4_K_M, 컨텍스트 4096이면? | FP16으로 잘못 계산해 "16GB라 부족" | 약 5.8GB, GPU에 전부 올라감 (계산값) |

## 2. 요구사항

명세서의 필수 요구사항(F2001~F2012)은 그대로 두고 도메인에 맞게 표현만 바꿨다. 심화는 F2014·F2015·F2016을 선택했고,
도메인 특화 기능(F2010)과 품질 장치(F2017)를 세분화·추가했다.
